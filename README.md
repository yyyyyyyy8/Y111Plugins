# Y111Plugins

用AI工具到处抄的小插件，捣鼓着玩

## 添加插件源

在游戏内 `/xlsettings` → `Experimental` → `Custom Plugin Repositories`，
添加下面这个地址：

```
https://raw.githubusercontent.com/yyyyyyyy8/Y111Plugins/main/pluginmaster.json
```

保存后打开插件安装器，搜索 **Map Gather** 即可安装。

## 插件列表

| 插件 | 内部名 | 版本 | 说明 |
| --- | --- | --- | --- |
